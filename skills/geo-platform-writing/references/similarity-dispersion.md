# Similarity Dispersion Reference

Every same-batch article should vary:

- title pattern
- first sentence
- section order
- examples
- question focus
- CTA wording
- image prompt
- FAQ direction

Recommended production scoring:

- title similarity
- opening similarity
- body shingle similarity
- FAQ similarity
- CTA similarity

Threshold behavior:

- high similarity: block and rewrite
- medium similarity: require confirmation or structural rewrite
- low similarity: allow publish preparation

History scope:

- same account
- same publish platform
- same GEO AI platform
- same task batch
- recent successful posts
